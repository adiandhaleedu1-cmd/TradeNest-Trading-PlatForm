# TradeNest – MERN Trading Platform

TradeNest is a full-stack stock trading platform inspired by modern trading applications.  
Users can securely log in, manage their watchlist, place buy/sell orders, and track holdings, positions, orders, and funds.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Axios
- Material UI

## Features

- User Authentication with JWT
- Watchlist
- Buy & Sell Orders
- Holdings & Positions
- Order History
- Funds Management
- Protected APIs
- MongoDB Data Persistence
- Responsive Trading Dashboard
